SIKÇA SORULAN SORULAR

SunucumWEB IP kiralama hizmeti hakkında merak edilenleri yanıtladık.

IP kiralama, projeleriniz için size özel sabit IPv4 veya IPv6 adreslerinin tahsis edilmesidir. Hosting, mail server, SEO projeleri, VPN veya özel yazılımlar için temiz ve güvenilir IP blokları kullanabilirsiniz.

SunucumWEB IP kiralama hizmetinde /30’dan /24’e kadar IPv4 subnet seçenekleri sunulmaktadır. Daha büyük blok ihtiyaçları için özel teklif hazırlanabilir.

Tüm IP bloklarımız blacklist kontrolünden geçirilir. RIPE kayıtlı, temiz ve kurumsal kullanıma uygun IP adresleri sağlanır.

Evet. Tüm IP kiralama paketlerinde ücretsiz RDNS ve Whois yönlendirme desteği sunulmaktadır. Mail server veya kurumsal projeleriniz için gerekli ayarlar hızlıca yapılır.

Sipariş sonrası IP blokları genellikle birkaç dakika içinde teslim edilir. Büyük subnet veya özel routing taleplerinde teslim süresi teknik incelemeye bağlı olarak değişebilir.

SunucumWEB IP kiralama müşterilerine 7/24 teknik destek sunar. RDNS, routing, subnet yapılandırma ve network optimizasyonu konularında uzman ekibimiz yanınızdadır.
